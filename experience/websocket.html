The full channel: one long-lived socket you write frames into and read frames out of, both directions, staying open. CDP and WebDriver-BiDi are exactly this — so mapping this one socket maps Playwright, Puppeteer and Selenium-BiDi too. Type a frame, send it, watch the echo come back.

How this is wired: the browser's native WebSocket. Default target is a public echo so you can see the round-trip with zero setup; point it at your own endpoint (or the 8 broker) to drive real BiDi. This is the browser twin of the wire's wsx atom — and of the conformance test, which stands up its own RFC6455 echo server and drives wsx against it: we made the channel, we send into it, events come back. Unlike sse, here you can push upstream.
