mjpeg CHANNEL · afferentwire

The afferent media plane. multipart/x-mixed-replace: the server keeps replacing one image forever, so a single <img> becomes live video. This is how you watch a device or browser screen without any player.

session idle
How this is wired: the browser natively decodes multipart/x-mixed-replace, so we just point an <img src> at base + /stream?session=<id> on the collector — the same route probeMJPEG checks. Gotcha we hit for real: /stream WITHOUT ?session= returns a text/plain usage line, not the mjpeg multipart — a lazy probe reads that as "drift" that is not there. The invocation has to be faithful.
